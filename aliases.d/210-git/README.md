# 210-git

Ajustes mínimos para personalizar tu identidad global de Git.

## Funciones
- git_email "correo@example.com": ejecuta git config --global user.email ....
- git_name "Nombre Apellido": ejecuta git config --global user.name ....
- git_identity_here "Nombre Apellido" "correo@example.com": configura user.name y user.email en el repo actual.
- git_coauthor "Nombre Apellido" "correo@example.com": imprime el trailer Co-authored-by listo para commits.
